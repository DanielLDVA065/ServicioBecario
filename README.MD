# Proyecto de clasificación de imágenes usando Deep Learning con CIFAR-10, PyTorch y FastAPI.

El sistema permite entrenar un modelo CNN y realizar predicciones desde una interfaz web usando una API local.

# Tecnologías usadas

- Python
- PyTorch
- Torchvision
- HuggingFace Dataset
- FastAPI
- Uvicorn
- HTML
- CSS

# Dataset

Se utilizó el dataset CIFAR-10:

Clases:
- airplane
- automobile
- bird
- cat
- deer
- dog
- frog
- horse
- ship
- truck

Dataset obtenido desde:

https://huggingface.co/datasets/uoft-cs/cifar10
